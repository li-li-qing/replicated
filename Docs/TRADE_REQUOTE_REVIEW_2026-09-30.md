### 1.2 前一份六页截图的独立故障

该报告属于另一个玩家，与本次樱花果截图不是同一笔逐项成本证据。它显示：

- `rawRows=8`、`displayRows=8`、货率已ready：货率数据已经返回。
- `after_ask ... nil,nil,nil,nil`：当前直接价格读取无可用值，不等于已搜过且市场无货。
- `paused=true / native_auction_visibility_unknown`：原生拍卖可见性未知。
- `itemType=3545 / searchName=燕麦 / fallbackState=queued / priority=background / queueLength=12`：当前尚未发送名称搜索，后面12项排队。
- `auctionOwnership.pending=false / eventBound=false / fallbackSearch.status=idle`：不是等一个已发出名称搜索的服务器回包，而是卡在本地准入。
- `entries=2 / hits=0 / misses=244 / refreshPending=0`：244是本地缓存读取未命中次数，不是244次联网；旧Describe还漏计未缓存身份的pending。

`known=false`时`visible=false`不是“确认已关闭”。截取时加载后约12.2秒，不能称该玩家已等了10分钟；10分钟停滞来自另做的离线模拟。截图不是完整可校验文本，本轮未宣称验证其分页校验和。

### 1.3 查到的代码缺陷与修补

**A. 手动刷新只有force标志，不等于取得本次挂单。** 旧force跳过插件TTL后仍可接受`GetLowestPrice`的正数；仅有返回数值，无法证明它对应本次最新挂单。离线让该getter保持旧值、名称搜索提供594/8800时，可复现双击后仍用旧价。本轮将Trade显式行/列表材料刷新标为`requireListing=true`，走现有受归属保护的名称搜索，从本次返回的同物品挂单总价与数量计算一口单价。普通后台Ask/Read协议保留，不笼统断言所有客户端的GetLowestPrice都错误。

**B. 新价被异常保护暂存后，被当作“已成功刷新旧价”交付。** 保留材料服务2.5倍跳变规则。对显式挂单重验，首次待复核不发ready；同一用户动作内最多增加一次独立名称搜索。通过原有校验才更新；第二次仍未通过则明确review_required，保留旧价。不重复消费同一个回包来伪造“两次确认”。取消最后消费者后，已发出的首个观察自然结束，不追加第二个查询。

**C. 另一个消费者的旧TTL命中能提前完成正在重验的行任务。** 旧路径在共享去重之前检查缓存，直接Publish ready，Trade按相同物品事件结算。现在相同请求身份已有显式重验时，普通请求先合并到它；通过新挂单校验后，只使同品质旧TTL及旧失败缓存失效，不清其它材料/用户配置。

**D. 无法确认可见性时无限占住pending。** 未发包的本地等待与已发包的Native在途分开，共享总容量64。普通可独立直接报价的后续材料能继续。可见性持续unknown时，每项进入未知等待起最多45秒转为明确blocked并释放消费者；这不是整批完成时长保证。已确认玩家打开拍卖行仍等待关闭，不抢搜索；无令牌已发包响应仍由既有超时隔离。本地blocked不写“无货”负缓存。等候恢复保持同优先级FIFO。

**E. 有旧数字就盖住重验状态，详情按钮还被禁用。** 保留旧数字，同时明确重验进度、失败/受阻和原价状态。货率fast-publish与完整材料投影共用任务状态，不再把active/blocked改回ready。详情有可拍卖材料即允许再次刷新；浮窗和主页面显示终态原因。真实双击回调已接到行命令，新增端到端测试证明已完成的货物再次双击会新增请求，而非只检查onClick函数存在。

**F. 诊断不完整。** pending独立于已缓存entries计数；生成Describe不再触发冷存档加载。原生可见性既有按需采样附带UIC、方法/许可、返回类型、内容与父链证据；Describe只复制已取得的有界事实，不新发请求或自动打开窗口。

### 1.4 明确不假装修好的边界

仅凭六页旧截图不能确定该客户端为什么不给可见性事实：内容尚未创建、方法/许可或返回结构仍要按实际证据区分。本补丁修复无限卡住和误导状态，**不会把unknown猜成已关闭**。仍拿不到可靠可见性时，名称搜索会明确受阻，而不是保证必然查到价。可手动打开一次原生拍卖行，再关闭后重试；这是尝试让原生内容初始化/形成可见性证据，不保证所有客户端都适用，也不需要启用插件拍卖助手。

名称搜索只读取本次返回的有界结果集（沿用最多20条、当前搜索页）；以该集合中的同身份可用一口价计算。没有未经许可跨页/排序，也**没有证明这是全市场所有页的绝对最低单价**。没有合适挂单或数量不可靠时保持明确失败，不用竞拍起价冒充能立即购入的成本。
