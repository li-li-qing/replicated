# 个人工作台 / Personal Workspace 实施与验收清单

基线：用户上传 20260918-082613 + 已交付 .18.246；旧版只参考信息组织，不移植旧 Runtime。
已批准：可定制多卡片首页、运行状态、具名收起、我的关注、统一外观；本轮新增左侧导航自定义。

## 约束与边界
- Lua 5.1 / toc.g；无 require、无新的 Native API、无跨模块业务写入；Presentation 仅调用所属 Feature 的 Commands。
- FeatureRuntime 拥有启停；WidgetHost/WindowShell 拥有窗口状态；旧业务 Store 继续拥有追踪/隐藏。
- 新 v3.workspace 只保存导航/卡片/列表排列/外观。业务开关、窗口几何、实际进度不进入新 Store。
- 自定义、导航、诊断、打开首页不隐式启用任何功能；按钮显式标明“启用并打开”。
- 仅事件或明确操作刷新。列表池化；不增加 Tick，不后台运行全量诊断。
- 每个写入走既有持久化事务，失败回滚。旧 Store canonical/schema 不随 UI 修改。

### 使用入口及可重复检查

| 目标 | 入口 | 预期 |
|---|---|---|
| 常用功能不用下拉 | 左栏“自定义”→左侧导航→选择→加入常用 | 首页之后优先显示，重载仍保留 |
| 更改功能顺序 | 同页“上移/下移” | 只改显示，不停用/启用业务；常用与普通分别排序 |
| 找回隐藏项目 | 左栏“显示全部”或工作台“全部条目” | 可恢复；首页和系统入口不能被隐藏 |
| 查找真正已开启项 | 左栏“已开启”/顶栏运行数量→功能状态 | 即使个人导航隐藏也不掩盖运行态；故障数仅运行时标记，不是全量诊断结论 |
| 定制首页 | 今日总览“自定义首页” | 日常、周常、活动、债券、跑商可隐藏/显示/排序；资源摘要可单独隐藏 |
| 列表取舍 | 日常/活动页或首页卡片“自定义”→我的关注 | 搜索、筛选，勾选含义由关注/取消按钮表达；批量仅当前结果 |
| 所有条目都不想做 | 我的关注→取消当前结果 | 明确空配置有效；日常操作不覆盖周常 |
| 只想换排列 | 置顶/上移/下移/自动排序 | 不修改任务进度、活动时间及事实来源 |
| 辨认收起窗口 | 悬浮窗口“—” | 显示恢复符号和功能标题，不再只有相同小方块；点击标题恢复 |
| 找回已隐藏窗口 | 工作台→悬浮窗口→显示/模块设置 | 不把窗口隐藏当功能停用；未启用的模块要求明确开启 |
| 调整风格 | 工作台→界面外观 | 经典深色、暖金深色、高对比；紧凑/标准密度，细参数仍在原设置 |
| 看模块状态与证据 | 模块左上角诊断 | 先看启停/已记录故障/窗口状态；生成/翻页仍使用原固定报告 |
