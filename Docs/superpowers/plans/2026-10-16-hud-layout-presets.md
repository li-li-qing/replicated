# HUD 布局预设与横纵排列

用户授权：增加几套布局预设；Buff、Debuff、技能 CD 各自支持纵排。沿用 HUD 调整、即时草稿预览和保存/取消入口。

## 设计与边界

- 经典横排、紧凑横排、均衡分层、纵向双翼、矩阵面板五套预设，另有恢复进入时布局。用户选择矩阵面板作为新一轮优化方向。
- 预设只调整当前 HUD 的组件几何；保留血条对齐基准、整体缩放、显隐、追踪、颜色与装分格式。选择后显示全部模拟便于对比。
- Buff、Debuff、CD 独立横纵，纵排列满后换列；每列数量/列数沿用既有容量上限。
- 参考[微软 HUD 可自定义位置及字号建议](https://learn.microsoft.com/en-us/windows/uwp/gaming/accessibility-for-games)，具体几何按当前插件血条代理及固定组件槽位设计。

## 经典横排重叠修正

用户指出经典横排施法条与 Debuff 重叠。原因是预设直接复用历史默认的施法条偏移 `y=0`，条和文字落在 Debuff 图标区。仅修正经典预设的施法条 `y=36`、技能 CD `y=104`，为固定高度的施法文字预留空间；不迁移历史默认或覆盖已有用户坐标。

新增两个先失败后通过的回归，分别运行实际校准预览与正式 Renderer，覆盖自身/目标、两行 Debuff 满容量、0.5/0.75/1/1.25/2 倍 HUD 缩放，并检查施法条与 Debuff、施法文字与 CD 不相交。

## 矩阵面板优化

用户反馈旧方案缺少结构与整齐感，并选定“矩阵面板：横向边缘对齐”。新增推荐预设：状态图标 25px、间距 4px，按血条宽度自适应 6～13 列、最多两排；装备 20px 分两列围绕血条；职业与数值两行；施法与 CD 使用相同外沿。保留当前代理、颜色、显隐与装分格式，不自动替换用户存档。

显式横排改为固定列宽并齐左，缺项和末行不再重新居中；`default` 仍保持旧路径。校准 detached 投影补齐真实装备排列代际，保证 v3/v5 的预览与正式 HUD 一致。

完整分享附加可选 `HUDORDER`，导入只重算新旧装备槽差，不改变本地排列代际。旧包不含该行时保持旧语义；非法、重复代际或重算越界在任何写入前拒绝。

新增反例覆盖固定列、矩阵选择/保存与颜色保持、大小血条和缩放、目标名字小缩放避让、跨代完整分享、宽布局保存不被截断。独立复核补测 42 次 v3↔v5 完整分享、336 例 Runtime/grid 对照及保存失败补偿；最终无遗留主要问题，跨代整数取整最大差 1px。仍须 RU 客户端视觉验收。
