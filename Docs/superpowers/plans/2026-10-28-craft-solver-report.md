# CC-01 制作计算交付记录

作者：Replicated；QQ群：1104129461

## 已实现

- `rs_craft_plan_domain.lua`：展开状态只影响显示；手动分配决定买做，购买节点停止下游劳力。购买限制同时覆盖普通购买和 raw 基材回退。旧边际算法及 32 次翻转已删除。
- `rs_craft_plan_solver.lua`：先读取完整可达 DAG，再按拓扑顺序累计共享需求，按规范身份库存抵扣一次；枚举每节点 `0..ceil(shortage/output)` 批次及剩余购买量。无法购买的候选仅保留足量制作。没有收益的额外批次不进入搜索。
- 现金与含劳力分别维护最优候选，同价选择总批次数更少者。只以已确定的非负成本剪枝；有分数铜价/折价时禁用浮点下界剪枝，并用最终评估器顺序比较完整候选。
- 无价、未知制作路线、费用未知、劳力未知均保留数据不足语义；已知 base 无配方不算未知路线。现金证明不依赖劳力完整性。旧报价或当前询价失败/无货/进行中仅可支持参考估算，不支持当前价格最优证明。
- 精确身份冲突、模糊库存、别名冲突明确 `unsupported`，不伪称最优。图保留 512 节点、4096 边、24 深度、64 目标限制；库存及背包快照各限制 4096 条。
- 缺失数值与非法数值分开：NaN、Inf、负数、超范围输入拒绝；单条候选现金/数量越界局部跳过，避免一条昂贵路线杀掉其它合法路线。累计劳力越界只影响含劳力结果，现金仍能求解。

## 接口

共享契约中的 Create/Step/GetSnapshot/Resume/Cancel 全部提供；另有 `D.PauseCompareJob(job, reason) -> bool` 供 Feature 的墙钟预算暂停。`StepCompareJob` 返回 `status, usedUnits`。

整体状态使用 `searching / paused / completed / unsupported / cancelled`；完成时每个目标独立给出 `optimal / incomplete_data / infeasible / unsupported / unavailable`。初始即有两项推荐对象，`available=false`；基线 manual/raw/buy 可以尚未准备。缺少劳力折价时 combined unavailable。取消优先于此前已完成状态。

`GetCompareSnapshot` 仅返回状态、基线和最优结果引用，不复制/暴露内部搜索图；消费者应当只读这些结果。输入由 Feature 提供 detached 值，job 不改输入。`D.Compare` 使用同一 job，并额外限制 100 万工作单元，不保留另一套算法。

协程在图准备、身份匹配、库存扫描、评估复制、边传播、候选保存及回滚中逐项让出执行权；默认每轮 100000 搜索状态暂停，Resume 保留栈并重置单轮预算。Feature 负责 50ms 调度、每回调最多 200 units、2ms 软截止及 10 秒墙钟暂停。

## 本轮证据

- 首轮失败反例：混合批次 `X×3、有 A×1、买 X=10、买 A=100` 旧比较未给出 20；展开中的购买节点错误多计下游劳力。先失败 0/2，后通过。
- optimizer：Lua 5.1 **18/18**。包含 16 条制作劳力 `10,20,15,25,15,25,20,30,50,60,55,65,55,65,60,70` 与整件买 0；80 个固定随机种子小型 DAG 对独立全枚举核对现金、含劳力、共享库存、多目标和同价批次；合法 512 节点边界；图/数值上限；暂停、继续、取消；交易限制及未知数据。
- library：Lua 5.1 **64/64**。原 66 条中删除 2 条旧边际辅助算法专属测试，其余更新为完整整数搜索语义；保留原有未提交输入。
- 审查反例新增且先失败后通过：10000 件整买超现金范围但制作一批只花 1，仍能选出合法制作；累计劳力超过 1e9 时仍找到现金 0 的两批方案，不让劳力上限错误裁掉现金最优。
- 运行命令：在 `replicatedsuite` 目录执行 `python -X utf8 -B -c "from lupa.lua51 import LuaRuntime; l=LuaRuntime(); l.globals().dofile('tools/rs_craft_optimizer_tests.lua')"`，library 同理替换脚本名。

这些是合成配方及本机 Lua 5.1 离线证据。复杂图可能暂停且仅返回当前最好可行方案；未声称所有复杂链已完成全局证明，也未验证真实 RU 赤石制作链、游戏调度时延或用户视觉体验。未提交、推送或发布。
