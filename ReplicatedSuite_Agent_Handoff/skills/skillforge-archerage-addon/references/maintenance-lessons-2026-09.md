# 2026-09 开发反馈：可复用案例与证据等级

本页不是“所有问题已经修好”的清单。素材是本次连续开发对话、用户现场报告和已交付补丁；本次技能维护读取相关源码和说明，但没有重新运行插件、Lua回归或RU客户端。历史测试记录属于**已有实验报告**，不冒充本轮新执行。

证据标签：**U** 用户提供的现场症状/日志；**S** 本轮核对的源码符号/调用结构；**R** 已交付说明和历史测试记录；**H** 尚需新环境验证的解释/参数。同一个案例可同时包含已确认机制与待确认具体现场归因。源码不全在一个提交中，按[来源清单](maintenance-evidence.json)中的文件/包摘要定位；技能自身不依赖能访问这些原包才能理解下列契约。

## 经验不是未经验证的新修复

具体构建号、397项、189位置、9215字节以及批次4项都只用于识别来源/构造反例。新的任务必须重新核对当前工程和输入，不能把这些数字直接写成全局限制；不要导入历史原档替代用户最新配置。

本轮新增AR-09～AR-26为由上述经验构造的**行为评测题**，带可观察评分条件，不是18次游戏测试结果。读题回答只能算方案验证；真实模型基线、加载技能的前向回答、独立评分和RU实机结果需要分别保存。包结构与链接通过不证明任何一个新行为案例已通过。
