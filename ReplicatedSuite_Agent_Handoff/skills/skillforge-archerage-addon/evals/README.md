# 行为评测不是包结构测试

本修订保留26道旧行为题，新增AR-27～AR-52共26道压力题；共52道行为题、27道触发题。这里是**待执行规格**，不是已通过的Agent测试。

## 有独立模型工具时

使用相同模型版本、工具权限、输入材料和预算。对每题分别运行“不载入本技能”和“载入本技能”两个独立会话；不向被测模型提供expectations或rubric，避免泄题。固定输入先后、记录模型/日期/参数/工具调用/原始回答；需要源码的题保持相同可访问材料。模型随机性应多次采样，记录样本数，不只挑成功回答。

独立评审按每条expectation给0或1分；新题出现critical_failures任一项整题为0。区分“正确识别阻断并不谎称完成”和“实际代码修改/实机执行成功”，题目无访问权限时前者可以得分。记录评分理由与引用回答片段，不能用简单关键词计分。

触发题只评trigger/no_trigger/conditional及理由；conditional应先确认真正缺失的宿主信息，不重复询问上下文已明确的服务器。

## 无独立模型工具时

执行`tests/`验证工具与结构，人工检查主题覆盖；所有行为执行状态保留not_run。不给自写标准答案计分，不把新增题数、结构链接通过数或测试断言数报告成“正确率”。用户实机反馈另做记录，不能被模型评测替代。

## 留存最少结果

每次真实运行另建结果文件，包含case_id、arm（without/with）、model/version、日期、输入与技能摘要、工具范围、原始回答路径、逐项分数、critical_failure、审阅者、未执行原因。不要把分数写回题库当作永久成绩；题库修订后旧结果的适用版本须可追踪。
