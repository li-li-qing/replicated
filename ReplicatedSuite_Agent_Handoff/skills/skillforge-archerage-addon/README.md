# skillforge-archerage-addon

修订：**2026.09.13-r2**。面向 ArcheRage RU / Replicated Suite 的开发与排障技能，不是游戏插件补丁。

## 安装/更新

把完整包中的 `skillforge-archerage-addon/` 放回你原来启用这个技能的目录，替换同名技能内容。不要把它放入游戏 Addon，也不要并排保留两个同名有效版本。具体发现、启用或重新加载方式取决于你使用的Agent宿主；本包不自动修改宿主设置。

增量包只适用于本次上传的旧技能，基线ZIP SHA256：

```text
95aaf758344d8c493d2150aacd964dcee06b36fdb0202bcee43b93a4623e2a42
```

原包没有额外运行脚本，本修订增加四个标准库Python工具。Python 3.10+仅在运行工具时需要；读取规则本身不依赖Python，不要求安装其他技能或联网。

## 内容入口

主入口是 [SKILL.md](SKILL.md)，按任务读取参考，不要一次性把所有文档粘进提示词。新增重点是PVP事实时效、首领计时、HUD组件完整接线、模板导出/旧默认兼容，以及真实验证边界。

四个工具的命令、返回码、作用范围和限制见[工具说明](references/verification-tools.md)。所有报告数据保持本地，输出文件默认不覆盖；任何工具都不操作游戏存档、不自动修改项目、不调用剪贴板。

## 实际验证与待验证

本轮工具回归共37个测试方法：35通过、0失败、2跳过；两项需要真实Lua5.1解释器。本环境无Lua5.1，相关门禁实测返回blocked，并未用5.4替代成功。另以实际项目的Lua分页器在Lua5.4上生成文本，与新Python接收器进行16组纯协议互通测试，通过；这不是Lua5.1或RU实机测试。

52道行为题、27道触发题均是评测规格；新增26道行为题与10道触发题。没有运行独立Agent A/B，不能由题目数量得出正确率提高。评测方法见[evals/README.md](evals/README.md)，本轮验证记录见[validation/results.json](validation/results.json)。

本包不携带游戏源码、UDF、原始玩家报告、截图、账号配置或解释器二进制。旧来源记录保留原证据等级，不把历史测试搬成新成绩。
