# 状态显示：一键追踪、图标与持续留存（2026-09-12）

## 本轮行为

本说明替代旧计划中“冻结按钮固定当前一帧”的定义；它不修改旧配置格式。

### 内置库

默认分类为“全部内置 Buff / Debuff（推荐）”：当前共 397 个不同状态（393 个职业技能效果和 4 个隐藏/特殊状态）。旧 `all` 分类仍保留 393 个职业效果，旧包名和导入版本水位保持兼容。推荐包不包含尚未实现实时读取的技能 CD。

点击“一键加入追踪”只提交一次耐久保存事务。成功后清除管理页的搜索/类别筛选，切到“已追踪（含未出现）”，从真实保存集合读取条目；不是等待状态出现在身上才显示。未知极性保留在 `tracked.auto`，显示“自动识别”，表示已经追踪、在 Native 暴露正负类型时进入对应 HUD。不能把全部技能效果强行标为 Buff 或 Debuff。

移除发行界面的“补齐新版”按钮，保留原内部 `newOnly` 方法和旧存档字段。导入不是持续绑定；取消一条后重载不会自动恢复，主动再次导入相同包才会重新选择该条。保存失败时保持当前页面，显示失败原因，事务回滚不留下半批选择。

### 图标

内置库原先没有 icon 列，目录投影还把 `iconPath` 写成空字符串。现在与管理表共用图标单元格，可见行只提交 ID 到 Feature 的有界队列，Native 不在行渲染回调中执行。一个最多 64 ID 的队列通过现有 Scheduler one-shot 每批最多 8 个 ID，调用共享 BuffMetadataV3 的缓存解析。

共享缓存正、负结果都限制在 512 条，用环形 FIFO O(1) 维护。空返回表不会被当作成功；已有名称但缺图标可做一次有限补全，仍无图标时缓存结果，避免每次重绑重复查询。真实图标缺失时显示现有 unknown 图标，不猜文件名。

图标读取在本页可见的管理/内置库页签运行。切换到 HUD/导入导出、隐藏页面后取消队列；过期回调不得操作新一轮队列。功能未启用也允许浏览/导入目录并显示图标，不启动战斗采集。

### 持续留存

先启用状态显示，再点击“冻结列表（留存）”。既收集当前已观察状态，也持续收集随后出现的 Buff、Debuff、Hidden；短状态消失后记录仍存在。自己和目标分开以 ID 去重，切换目标不删除历史，不制造无限目标身份缓存。

留存开启时持有明确的 Feature Consumer，所以隐藏管理页面不停止采集。停止并清空、关闭功能和插件内重载会释放 Consumer、清空记录。清空记录是独立按钮：只删除本轮记录、继续捕获随后状态。取消追踪不删除留存记录。

复用原 aura lane 的 50ms 兜底；留存开启时 BUFF_UPDATE/DEBUFF_UPDATE 事件立即通过共享 Aura 服务读取，不再等待 120ms。显式 `forceRefresh` 处理同一时钟刻度下的缓存，不改变其他消费者的常规 TTL。管理历史从不写入实时 HUD 的 laneData，因此 HUD 倒计时和到期移除继续正常。

每次自己/目标各读取最多 128 Buff、128 Debuff、128 Hidden；每 scope 留存最多 1,024 个 ID，合计最多 2,048 条。超限保留早期记录，明确显示上限和未记录的新观察次数，不悄悄淘汰。读取不完整时不把“没读到”断言为“已消失”。只能保证已经被 Native API 暴露且实际观察到的状态得到留存，不能还原开启前已消失或接口未暴露的瞬时状态。

## 完成状态

用户确认单位连线、范围辅助当前约定范围已经完成。Registry 只使用现有 `navigationDevelopmentState="complete"` 展示覆盖：移除未完成后缀并进入完成组。保留技术能力边界、API限制、采样/绘制/保存代码；不声称实现全单位网络或技能自动半径。

## 数据与所有权

- 原始事实：AuraObservationV3 / BuffMetadataV3。
- 生命周期、持续留存及选择命令：BuffDisplay Feature。
- 持久化：既有 schema6 / Transport3 事务。无迁移、无白名单、无改指纹。
- 视图：RSUI 虚拟化列表；旧页签、字段、存档键保留。
- 分页自检：不改操作方式，只附带现有健康数据中的追踪/导入/留存计数，标识 `status-retain-library-1`。不因打印报告发起 Native 扫描。

## 验证边界

新增 33 项离线回归覆盖：后到短状态、过期保留、HUD隔离、事件边捕获、同时间戳缓存、跨页生命周期、容量上限、事务失败回滚、真实保存与重读、图标分批与缓存、关闭功能仍浏览目录、导航完成标记。

测试使用 Lua 5.4 加兼容垫片；Native 事实/存储、调度和控件宿主为模拟。未执行 RU 客户端、Windows Lua5.1 或像素布局验收。不把通过模拟中的 20ms 事件样本解释为客户端所有短状态都必然能被 API 捕获。

## 实机验收

覆盖全部修改文件后使用插件内“重新加载文件”，无需清档。

1. 内置库默认推荐包，点击一次后显示已追踪 397 项（用户原有额外选择可能更多）；已有条目不重复，保存失败明确可见。
2. 目录上下滚动，看图标渐进补齐；缺资源显示 unknown。退出页面不继续查询图标。
3. 取消一个条目，重载后仍取消；再次主动导入该包会重新添加。
4. 开启留存后再触发短 Buff/Debuff，消失后管理行仍在，实时 HUD 已到期消失。
5. 自己/目标/隐藏来源均覆盖；切目标或关闭管理页不清历史；清空记录继续捕获；关闭功能和重载清空。
6. 单位连线与范围辅助无未完成后缀，功能启停与此前一致。
7. 有异常时继续用原“打印自检报告/上一页/下一页”反馈，报告 tracking.patch 应为 status-retain-library-1。
